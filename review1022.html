1．心電図は電気現象、収縮は機械現象

ここを説明できるようにしよう

P・QRS・TとPQ・QTを区別し、心筋の長い不応期の意味を説明できる。

押さえるポイント

  • Pは心房、QRSは心室の脱分極。
  • PQはP波開始からQRS開始、QTはQRS開始からT波終末。
  • 心筋の長い不応期は収縮の加重・強縮を起こしにくくする。

脱分極は細胞膜の電気的な興奮、再分極は膜電位が元の状態へ戻る過程です。心電図はこれらの電気現象を体表から記録します。P波は洞房結節そのものの電位ではなく、主に心房筋の脱分極を反映します。

洞房結節で始まった興奮は心房、房室結節、His束、脚、Purkinje線維を経て心室へ伝わります。刺激伝導系と、主に力を発揮する固有心筋の役割を分けましょう。

QT間隔は心室の脱分極開始から再分極終了までです。T波が再分極に対応します。不応期とは刺激に反応して再び興奮しにくい時間です。心筋では長く、収縮後に拡張して血液を受け入れる周期を保つうえで重要です。

P波心房筋の脱分極洞房結節そのものの波ではない
QRS群心室筋の脱分極Purkinje線維だけの興奮ではない
T波心室筋の再分極収縮力の大きさではない
PQ／QT房室伝導／心室の興奮全体の時間始点と終点を図式化する

資料を閉じて説明してみよう

  • P波が出る前に興奮が始まる通常の部位はどこですか。
  • QT間隔はT波の始まりと終わりのどちらまでですか。

確認問題（各問1つ選択）

問1　通常の心電図のT波が主に示すのはどれか。

解答・全選択肢の解説を開く

正答：5

  1. 心房筋の脱分極：心房筋の脱分極はP波です。
  2. 大動脈弁の開放：弁開放そのものを記録する波ではありません。
  3. 洞房結節だけの脱分極：結節単独の電位をT波とは呼びません。
  4. 房室弁の閉鎖：弁の動きは機械現象で、T波の定義ではありません。
  5. 心室筋の再分極：心室筋の再分極に対応します。

問2　心筋が骨格筋に比べて強縮を起こしにくい理由として適切なのはどれか。

解答・全選択肢の解説を開く

正答：5

  1. 活動電位が発生しない：心筋にも活動電位があります。
  2. 全く電気刺激に反応しない：心筋は電気的に興奮する組織です。
  3. 収縮蛋白をもたない：アクチン・ミオシンをもちます。
  4. 細胞内カルシウムを利用しない：カルシウムが収縮に関与します。
  5. 不応期が長い：長い不応期が連続刺激による収縮の加重を抑えます。

2．ミオトニアと痙縮を分ける

ここを説明できるようにしよう

収縮後の弛緩遅延と、他動運動への速度依存性抵抗を区別できる。

押さえるポイント

  • ミオトニアは収縮後に力を抜きにくい現象。
  • 痙縮は上位運動ニューロン障害に関連する。
  • 筋強直性ジストロフィーは筋以外の臓器にも症状が出る。

「筋が硬い」という言葉だけでは病態を区別できません。筋強直（ミオトニア）は、握った手をすぐ開けないなど、収縮後の弛緩が遅れる現象です。痙縮は、他動的に速く伸ばしたときの抵抗が増える特徴をもつ筋緊張異常です。

国試で典型的に扱う筋強直性ジストロフィー1型では、遠位筋や顔面筋の筋力低下・萎縮、ミオトニア、白内障、心伝導障害などを整理します。近位筋優位の病型もあるため、すべての型に「遠位のみ」と断定しません。

Duchenne型との比較では遺伝形式を分けます。筋強直性ジストロフィーは常染色体顕性（優性）遺伝、Duchenne型はX連鎖潜性（劣性）遺伝が基本です。

ミオトニア随意収縮後の弛緩遅延握った後に手を開きにくい
痙縮速度依存性の抵抗増加上位運動ニューロン障害
筋強直性ジストロフィー筋＋全身の所見白内障・心伝導障害など

  2. ミオトニア：筋強直を指す用語です。
  3. 測定障害：運動の距離調節などの障害です。
  4. 感覚失語：言語理解などの障害です。
  5. 失認：知覚された対象の認知に関わる障害です。

3．脳性麻痺：病型と粗大運動評価

ここを説明できるようにしよう

痙直型と不随意運動を主体とする病型を分け、GMFMの目的を説明できる。

押さえるポイント

  • 痙直型は痙縮、不随意運動型は運動・筋緊張の変動に注目。
  • 病型だけで個人の知的能力を決めつけない。
  • GMFMは粗大運動能力の変化をみる尺度。

痙直型では痙縮が中心で、両麻痺では下肢の障害が相対的に強いことがあります。アテトーゼはゆっくりした不随意運動を指し、不随意運動型では姿勢・運動に伴う筋緊張の変動も重要です。現在の分類と、教材で使われる従来の「アテトーゼ型」という呼称を対応させて読みます。

発話や運動の困難さだけで知的能力を判断せず、それぞれを分けて評価します。

GMFM-88は5領域88項目で、各項目は原則0〜3の4段階です。臥位と寝返り、座位、四つ這いと膝立ち、立位、歩行・走行・跳躍を扱います。GMFCSは日常の粗大運動機能をレベルⅠ〜Ⅴに分類する仕組みで、GMFMと取り違えないようにします。

痙直型痙縮速い他動伸張で抵抗が増えやすい
不随意運動型不随意運動・筋緊張の変動動きや姿勢で変化
GMFM-885領域・88項目原則0〜3点の4段階
GMFCS機能の分類レベルⅠ〜Ⅴ

資料を閉じて説明してみよう

  • GMFMとGMFCSは同じ採点方法ですか。
  • 発話が困難なことだけで知的能力を判断できますか。

確認問題（各問1つ選択）

問5　GMFM-88について正しいのはどれか。

解答・全選択肢の解説を開く

正答：3

  1. 心電図波形を測る：心電図検査ではありません。
  2. 神経伝導速度の単位で表す：点数で評価する運動尺度です。
  3. 5領域88項目からなる：粗大運動の5領域88項目を扱います。
  4. 各項目は必ず0か10点で採点する：各項目は原則0〜3点です。
  5. 成人の疼痛だけを評価する：粗大運動能力の変化をみる尺度です。

問6　不随意運動型の脳性麻痺を学習する際の理解として適切なのはどれか。

解答・全選択肢の解説を開く

  3. 発話の不明瞭さだけで知的能力を断定する：運動・発話と知的能力は分けて評価します。
  4. GMFMは知能検査である：粗大運動の評価尺度です。
  5. すべての例で下肢だけに障害がある：四肢・体幹など多様な障害があります。

4．アルコール：酩酊・離脱・栄養障害を分ける

ここを説明できるようにしよう

飲酒中、減量・中断後、ビタミン欠乏の違いを説明できる。

押さえるポイント

  • 振戦・発汗・けいれん・せん妄を整理する。
  • Wernicke脳症はビタミンB1欠乏が中心。

酩酊はアルコールを摂取した影響、離脱は長期の多量飲酒に適応した神経系でアルコールの量が急に減ったときの過興奮として整理します。同じ「飲酒関連」でも時間軸が違います。

離脱では振戦、発汗、頻脈などの自律神経症状が生じ、重い場合にはけいれんやせん妄を伴います。せん妄は注意・意識状態の変動を伴う状態です。重い離脱症状は医療対応が必要です。

Wernicke脳症はビタミンB1欠乏が原因です。離脱と同時に存在する場合もありますが、同じ病態ではありません。

離脱減量・中断に伴う過興奮振戦・発汗・けいれんなど
Wernicke脳症ビタミンB1欠乏離脱とは別の病態
肝性脳症肝機能障害に関連離脱とは別の原因

5．髄鞘とRanvier絞輪を分ける

ここを説明できるようにしよう

髄鞘の役割と、絞輪で起こることを説明できる。

押さえるポイント

  • 髄鞘は軸索を包む。
  • 絞輪は髄鞘の切れ目。
  • 有髄線維では絞輪間を跳ぶように興奮が伝わる。

髄鞘は軸索を覆う絶縁性の構造です。Ranvier絞輪は、その覆いが途切れる部分です。「絞輪が絶縁する」と逆に覚えないようにしましょう。

有髄線維では絞輪で活動電位が再生され、跳躍伝導が成立します。無髄線維の伝導と比べると、髄鞘と絞輪の組合せが伝わり方を変える点が重要です。

髄鞘軸索を覆う絶縁性の構造
絞輪髄鞘の切れ目活動電位が再生
跳躍伝導有髄線維の伝わり方無髄線維と区別

資料を閉じて説明してみよう

  • 髄鞘と絞輪を簡単な図に描けますか。
  • 絶縁する部分と興奮が再生される部分はどこですか。

確認問題（各問1つ選択）

問9　有髄神経線維で髄鞘が途切れる部分はどれか。

解答・全選択肢の解説を開く

正答：3

  1. 軸索終末：終末は情報を次の細胞へ伝える部位です。
  2. 樹状突起：主に入力を受ける突起です。
  3. Ranvier絞輪：髄鞘の切れ目です。
  4. シナプス小胞：伝達物質を蓄える小胞です。
  5. 細胞核：遺伝情報を含む構造です。

問10　有髄線維の伝導について正しいのはどれか。

解答・全選択肢の解説を開く

正答：3

  1. 絞輪が軸索を完全に絶縁する：絶縁性を担う髄鞘と混同しています。
  2. 髄鞘は神経伝導と無関係である：伝導の速さや様式に関係します。
  3. 絞輪で活動電位が再生される：髄鞘の切れ目で再生されます。
  4. 髄鞘の全区間で同じように活動電位を再生する：有髄線維では絞輪が重要です。
  5. 無髄線維だけで跳躍伝導が起こる：跳躍伝導は有髄線維でみられます。

6．腎機能低下と貧血をつなぐ

ここを説明できるようにしよう

腎臓と赤血球産生の関係を説明できる。

押さえるポイント

  • 腎臓は尿を作るだけではない。
  • エリスロポエチンは赤血球産生を促す。
  • 腎機能低下に伴い貧血が生じることがある。

エリスロポエチン（EPO）は、骨髄に赤血球を作るよう働きかけるホルモンです。腎臓の働きが低下すると産生が減り、貧血の原因になります。

腎疾患に伴う貧血には鉄不足や炎症なども関係します。腎臓だけ、鉄不足だけと一つに決めつけず、赤血球を作る仕組みから整理しましょう。

腎臓EPOの産生骨髄へ働きかける
骨髄赤血球を産生EPOの作用先
赤血球酸素を運ぶ不足すると組織への酸素供給が低下

  • EPOが主に働きかける場所はどこですか。

  5. EPO低下が赤血球産生低下に関係する：腎性貧血の重要な機序です。
