1．立ち上がり：位置・速度・加速度を分ける

応用編

ここを説明できるようにしよう

「上がっている」と「上がる速さが増えている」の違いを説明できる。

判断の順序

1 上向きを正と決める2 速度は位置の変化を見る3 加速度は速度の変化を見る

重心の高さを位置、単位時間に高さが変わる量を鉛直速度、その速度の変わり方を鉛直加速度といいます。高さが増えている間、鉛直速度は正です。上昇の勢いが弱まれば、上昇中でも鉛直加速度は負になります。

椅子から離れた後、身体が床以外に接触していない条件では、鉛直床反力から体重を引いた力が重心の鉛直加速度を決めます。加速度が上向きなら床反力は体重より大きく、加速度が下向きなら小さくなります。着座中は座面からの力もあるので、この式をそのまま使いません。

混同しやすい点を整理

見る量問いかけ単位
位置今どの高さかm
速度どの向きに、どれくらい速く動くかm/s
加速度速度がどの向きに変わるかm/s²

資料を閉じて説明してみよう

上昇中でも加速度が負になるのは、どんなとき？

静止立位では、床反力と体重はどうなる？

確認問題（各問1つ選択）

問1　立ち上がりの終盤、重心は上昇し続けているが、上昇速度は小さくなっている。上向きを正とした鉛直速度と鉛直加速度の組合せはどれか。

解答・全選択肢の解説を開く

正答：2

  1. 速度は正・加速度は正：上昇速度が増えているときの組合せ。今回は減速している。
  2. 速度は正・加速度は負：上昇中なので速度は正、上昇速度が減るので加速度は負になる。
  3. 速度は負・加速度は正：速度が負なら重心は下降している。
  4. 速度は負・加速度は負：下降しながら下降速度が増える状態を表す。
  5. 速度は0・加速度は0：重心が静止し続けている状態であり、上昇中ではない。

問2　椅子から臀部が離れ、足部以外は物に触れていない。身体重心の鉛直加速度が上向きの瞬間、両足に作用する鉛直床反力の合計はどうなるか。

解答・全選択肢の解説を開く

正答：5

  1. 常に0になる：床から力を受けて身体を支えている。0ではない。
  2. 体重の半分になる：半分なら合力は下向きになり、設問の加速度とは合わない。
  3. 必ず体重と等しくなる：体重と等しいのは鉛直加速度が0のとき。
  4. 体重より小さくなる：床反力が体重より小さければ、合力と加速度は下向きになる。
  5. 体重より大きくなる：床反力－体重＝質量×鉛直加速度。上向きの加速度では床反力が体重を上回る。

2．膝の検査：動かす方向と靱帯を結び付ける

応用編

ここを説明できるようにしよう

脛骨を動かす方向から、検査する靱帯を選べる。

判断の順序

1 大腿骨に対する脛骨の動きを考える2 前後と内外反を分ける3 靱帯と半月板を混同しない

前十字靱帯〈ACL〉は、脛骨の過度な前方移動を抑えます。後十字靱帯〈PCL〉は過度な後方移動を抑えます。「前方引き出し」は前方に動かしてよいという意味ではなく、その動きを止める靱帯の機能を調べています。

外反ストレスでは膝の内側が開こうとし、主に内側側副靱帯を調べます。内反では逆に外側側副靱帯を調べます。McMurrayテストは半月板の検査です。実際の診断は痛み、受傷機転、画像なども合わせて行います。

混同しやすい点を整理

検査・動き主な対象
Lachman／前方引き出し前十字靱帯
後方引き出し後十字靱帯
外反ストレス内側側副靱帯
内反ストレス外側側副靱帯
McMurray半月板

資料を閉じて説明してみよう

外反なのに、なぜ内側の靱帯を調べるの？

ACLとPCLが抑える動きを、自分の膝を見ながら説明しよう。

確認問題（各問1つ選択）

問3　大腿骨を固定し、膝を軽度屈曲して脛骨を前方へ引き出す。左右差と終末感から主に評価するのはどれか。

解答・全選択肢の解説を開く

正答：1

  1. 前十字靱帯：Lachmanテストに相当する。過度な脛骨前方移動を抑えるACLを調べる。
  2. 後十字靱帯：PCLは後方引き出しなどで評価する。
  3. 内側側副靱帯：内側側副靱帯は主に外反ストレスで評価する。
  4. 外側側副靱帯：外側側副靱帯は主に内反ストレスで評価する。
  5. 膝蓋靱帯：膝蓋靱帯は膝伸展機構の一部。前方引き出しの主な評価対象ではない。

問4　膝を約30°屈曲して外反ストレスを加えたところ、内側関節裂隙の開大に左右差を認めた。主に機能低下が疑われるのはどれか。

解答・全選択肢の解説を開く

正答：4

  1. 前十字靱帯：ACLの主な検査は前方引き出しやLachmanテスト。
  2. 後十字靱帯：PCLは脛骨の後方移動を抑える。
  3. 外側側副靱帯：外側側副靱帯は内反ストレスで緊張する。
  4. 内側側副靱帯：外反で内側が開くのを抑える靱帯であり、この条件に合う。
  5. アキレス腱：足関節底屈に関わる腱。膝の外反ストレス検査の対象ではない。

3．上肢装具：何の動きを補うかで選ぶ

応用編

ここを説明できるようにしよう

神経麻痺・変形・装具の目的をつなげて説明できる。

判断の順序

1 できない動きを確認2 補う方向を決める3 装具名を目的と結び付ける

装具名だけを覚えると、似た名称に迷いやすくなります。母指対立が難しいなら対立位を保つ、手関節が下垂するなら伸展位を支える、という順に考えましょう。

正中神経の低位麻痺では母指球筋の障害によって母指対立が難しくなります。手関節の支持が保たれていれば短対立スプリントが候補になります。橈骨神経高位麻痺による下垂手ではコックアップ・スプリントなどで手関節を支えます。尺骨神経麻痺による鷲手では、MP関節の過伸展を抑えてIP関節の伸展を助ける虫様筋バーなどを考えます。

混同しやすい点を整理

状態主な問題装具の例
低位正中神経麻痺母指対立が難しい短対立スプリント
高位橈骨神経麻痺手関節を伸展できないコックアップ・スプリント
尺骨神経麻痺の鷲手MP過伸展・IP屈曲虫様筋バー
スワンネック変形PIP過伸展・DIP屈曲PIP過伸展を制限するリング装具

資料を閉じて説明してみよう

対立スプリントは、どの指のどの動きを助ける？

スワンネック変形とボタンホール変形で、PIP関節の向きはどう違う？

確認問題（各問1つ選択）

問5　低位正中神経麻痺で母指対立が困難である。手関節の自動伸展は保たれている。母指を対立位に保持する装具はどれか。

解答・全選択肢の解説を開く

正答：3

  1. コックアップ・スプリント：主に手関節を伸展位で支える装具で、母指対立の保持が主目的ではない。
  2. 虫様筋バー：MP関節の過伸展を抑え、鷲手に対して用いる。
  3. 短対立スプリント：手関節の支持を大きく制限せず、母指の対立位を保つ目的に合う。
  4. 肩外転装具：肩を外転位で保持する。母指の対立は補わない。
  5. 尺側偏位防止スプリント：指の尺側偏位を抑える。母指対立不能とは目的が違う。

問6　PIP関節の過伸展とDIP関節の屈曲を示す指に対し、変形を抑える装具を検討する。最も適切な目的はどれか。

解答・全選択肢の解説を開く

正答：2

  1. PIP関節をさらに過伸展させる：スワンネック変形を強める方向になる。
  2. PIP関節の過伸展を制限する：スワンネック変形の特徴を踏まえ、PIP過伸展を抑える。
  3. 手関節を底屈させる：手関節には掌屈・背屈を用いる。指の変形を直接抑える目的でもない。
  4. 肩関節の外転を制限する：対象は指の関節であり、肩の外転制限は目的に合わない。
  5. 母指の内転だけを制限する：母指の内転制限では対象指のPIP過伸展を抑えられない。

QB専門問題 p.837（PDF 903ページ）：上肢装具の適応。

4．脳卒中の評価：機能障害と生活動作を分ける

応用編

ここを説明できるようにしよう

SIAS・Brunnstrom法・FIMを、評価したい内容に合わせて選べる。

判断の順序

1 評価する対象を言葉にする2 機能障害か生活動作かを分ける3 項目と採点方法を確認

SIAS〈Stroke Impairment Assessment Set〉は、脳卒中の機能障害を多面的に調べる評価セットです。麻痺側の運動、感覚、筋緊張、体幹、高次脳機能などに加え、非麻痺側の握力や大腿四頭筋の筋力も含みます。すべてを一律に6段階で採点するものではありません。

Brunnstrom法では共同運動から分離運動への回復を段階でとらえます。FIMは生活動作でどれくらい介助を要するかを評価します。FIMの5点は監視・準備、4点は最小介助です。「手を出していないから満点」とはなりません。

SIASの下肢関節可動域は膝を伸ばした状態で足関節背屈を調べ、非麻痺側の下肢筋力は座位で膝伸展を調べます。評価項目の名前に加え、どの姿勢で何を行うかもセットで確認しましょう。

混同しやすい点を整理

尺度主に知りたいこと混同しない点
SIAS脳卒中による機能障害非麻痺側の機能も含む
Brunnstrom法麻痺の回復段階ADLの介助量そのものではない
FIMADLの自立度・介助量運動13項目＋認知5項目、各7段階

資料を閉じて説明してみよう

非麻痺側の筋力を調べるのは、なぜ生活の理解にも役立つ？

声かけだけが必要な場合、FIMは完全自立？

確認問題（各問1つ選択）

問7　脳卒中患者の麻痺側運動機能に加え、感覚、体幹、視空間認知、非麻痺側の握力などを一つの評価セットで確認したい。適切なのはどれか。

解答・全選択肢の解説を開く

正答：4

  1. Barthel Index：ADLの自立度を評価する。設問の機能障害セットとは異なる。
  2. Glasgow Coma Scale：開眼・言語・運動反応から意識を評価する。
  3. 改訂長谷川式簡易知能評価スケール：認知機能のスクリーニングであり、麻痺側運動などは含まない。
  4. SIAS：運動機能以外や非麻痺側機能も含めて評価できる。
  5. Borgスケール：主観的な運動強度などを評価する。

問8　FIMの更衣を評価した。補助具は不要で、衣服を着る動作はすべて本人が行うが、順番を間違えないよう毎回声かけが必要である。身体的な介助はしていない。評点はどれか。

解答・全選択肢の解説を開く

正答：2

  1. 7点：安全・適切な時間内で、他者の助けなしに実施できる完全自立。声かけが必要なので該当しない。
  2. 5点：監視・声かけ・準備を要するが身体的な介助はないため5点。
  3. 4点：最小介助で、身体的な介助を要する場合。
  4. 3点：中等度の身体的介助を要する場合。
  5. 1点：全介助に相当し、本人が動作をすべて行う状態とは異なる。

5．脳幹の障害：顔と身体の左右を分ける

応用編

ここを説明できるようにしよう

延髄外側の障害で、顔と身体の温痛覚障害の側が異なる理由を説明できる。

判断の順序

1 顔と体幹・四肢の経路を分ける2 交叉の位置を見る3 皮質脊髄路の位置を確認

顔の温痛覚と体幹・四肢の温痛覚は、脳幹を通る経路が異なります。延髄外側の障害では、顔は病変と同側、体幹・四肢は反対側の温痛覚障害が代表的です。これを「全部同じ側」とまとめないことが大切です。

Wallenberg症候群では、嚥下障害、嗄声、病変と同側の運動失調やHorner症候群などがみられます。皮質脊髄路は主に延髄の腹内側を通るため、典型的な外側病変では明瞭な片麻痺を中心所見としません。病変の広がりによって所見は変わります。

混同しやすい点を整理

右延髄外側病変の例代表的な側・所見
顔の温痛覚右で低下
体幹・四肢の温痛覚左で低下
小脳へ向かう経路右の運動失調
疑核など嚥下障害・嗄声
皮質脊髄路典型的病変では保たれやすい

資料を閉じて説明してみよう

右延髄外側なら、顔と脚の温痛覚はそれぞれどちらで低下する？

「脳卒中だから必ず強い片麻痺」と考えてはいけない理由は？

確認問題（各問1つ選択）

問9　右延髄外側の限局した梗塞で典型的な温痛覚障害の組合せはどれか。

解答・全選択肢の解説を開く

正答：5

  1. 右顔面・右体幹四肢：顔と身体を同側にそろえている。体幹四肢は反対側が典型。
  2. 左顔面・左体幹四肢：顔は病変と同側の右で障害される。
  3. 左顔面・右体幹四肢：これは左延髄外側病変を考える組合せ。
  4. 両側顔面のみ：限局した片側病変の典型的所見とは合わない。
  5. 右顔面・左体幹四肢：顔は同側、体幹四肢は対側となる解離した分布に合う。

問10　典型的なWallenberg症候群で、錐体路性の明瞭な片麻痺が中心所見になりにくい理由はどれか。

解答・全選択肢の解説を開く

正答：3

  1. 延髄には運動に関わる線維が存在しないから：延髄にも皮質脊髄路などの運動路が通る。
  2. 小脳が随意運動の最終運動ニューロンだから：最終運動ニューロンは脊髄前角や脳神経運動核にあり、小脳ではない。
  3. 皮質脊髄路が延髄の主に腹内側を通るから：外側の典型病変から皮質脊髄路が外れやすいことによる。
  4. 錐体交叉が脊髄腰膨大部にあるから：錐体交叉は延髄下部にある。
  5. 温痛覚と随意運動が同じ線維を通るから：感覚路と運動路は別の経路として整理する。

6．高次脳機能：検査と生活の工夫をつなげる

応用編

ここを説明できるようにしよう

注意・記憶・半側空間無視を区別し、負担を減らす工夫を選べる。

判断の順序

1 どの課題で困るかを観察2 検査の目的を区別3 情報を整理して一つずつ伝える

注意障害では、気を保つ、必要な情報を選ぶ、別の課題へ切り替えるなどが難しくなります。最初からテレビや会話を加えて課題を複雑にするより、刺激を減らし、一つの作業に集中できる環境を整えます。

半側空間無視は、空間の一側に気付きにくい障害です。BITはその評価に用います。記憶が難しい場合は、短い手順表や予定表など、外に残る手掛かりを本人が使える形で準備します。「注意不足」と叱ることは、障害の説明にも対策にもなりません。

混同しやすい点を整理

調べたい内容検査・方法の例生活の工夫
半側空間無視BIT、抹消・二等分など見落とす側への探索を促す
注意の維持・切り替えTMTなど刺激を減らし、課題を一つずつ
記憶記銘・遅延再生の課題など手順表・予定表を活用

資料を閉じて説明してみよう

一度に多くの指示を出すと困る人に、どう伝える？

8．温熱療法：熱がどこで生じるかを考える

応用編

ここを説明できるようにしよう

伝導・対流・放射・変換を、治療方法と結び付けられる。

判断の順序

1 熱源に触れているか2 液体や気体が動くか3 体内でエネルギーが熱になるか

ホットパックでは、温かい物体から身体へ接触を介して熱が伝わります。これは伝導です。渦流浴では、流れる温水による熱の移動が関わり、主な様式は対流です。どちらも「温かい」ことだけで同じ分類にしないでください。

赤外線は電磁波による放射です。超音波では、音響エネルギーが組織で吸収され熱へ変わる作用があり、変換に分類します。温熱を用いる前に温度覚、循環、皮膚の状態、禁忌を確認します。感覚低下がある場所で「本人が熱いと言わない」だけを安全の根拠にしません。

超音波を水中法で行っても、温熱作用の分類は変換です。水は超音波を伝える媒体の役割を担います。「水を使うから対流」とは判断しません。

混同しやすい点を整理

主な熱伝達様式例考え方
伝導ホットパック接触で伝わる
対流渦流浴流れる水が熱を運ぶ
放射赤外線電磁波として届く
変換超音波の温熱作用別のエネルギーが組織内で熱になる

問15　温熱療法と主な熱伝達様式の組合せで正しいのはどれか。

解答・全選択肢の解説を開く

正答：3

  1. ホットパック―放射：ホットパックは接触による伝導を中心に考える。
  2. 赤外線―対流：赤外線は電磁波による放射。
  3. 超音波―変換：音響エネルギーが組織で吸収されて熱に変わる。
  4. 渦流浴―伝導のみ：渦流浴では流れる温水による対流が中心である。
  5. パラフィン浴―超音波による変換：パラフィン浴は主に伝導による。超音波を使う方法ではない。

問16　超音波療法を水中法で実施した。超音波の温熱作用について正しいのはどれか。

解答・全選択肢の解説を開く

正答：2

  1. 水を使うため、渦流浴と同じ対流だけで温まる：水はカップリング媒体であり、温水の流れを利用する渦流浴とは仕組みが違う。
  2. 組織に吸収された音響エネルギーが熱に変わる：直接法でも水中法でも、組織に届いた超音波のエネルギーが吸収され熱に変わる。
  3. 温熱作用が放射に変わる：赤外線のような放射への変更ではない。
  4. 水中法では音響エネルギーは身体に届かない：水を介して超音波を身体へ伝える。
  5. 直接法では変換だが、水中法では必ず伝導のみになる：方法が変わっても超音波の温熱作用は変換である。

酸素の大部分は赤血球のヘモグロビン〈Hb〉と結合して運ばれます。酸素飽和度は、酸素と結合できる場所のうち、実際に酸素が結合している割合です。運ぶHb自体が少なければ、飽和度が高くても血液中の酸素量は少なくなります。

問1

正答：2

  1. 速度は正・加速度は正：上昇速度が増えているときの組合せ。今回は減速している。
  2. 速度は正・加速度は負：上昇中なので速度は正、上昇速度が減るので加速度は負になる。
  3. 速度は負・加速度は正：速度が負なら重心は下降している。
  4. 速度は負・加速度は負：下降しながら下降速度が増える状態を表す。
  5. 速度は0・加速度は0：重心が静止し続けている状態であり、上昇中ではない。

問2

正答：5

  1. 常に0になる：床から力を受けて身体を支えている。0ではない。
  2. 体重の半分になる：半分なら合力は下向きになり、設問の加速度とは合わない。
  3. 必ず体重と等しくなる：体重と等しいのは鉛直加速度が0のとき。
  4. 体重より小さくなる：床反力が体重より小さければ、合力と加速度は下向きになる。
  5. 体重より大きくなる：床反力－体重＝質量×鉛直加速度。上向きの加速度では床反力が体重を上回る。

  5. 尺側偏位防止スプリント：指の尺側偏位を抑える。母指対立不能とは目的が違う。

  2. PIP関節の過伸展を制限する：スワンネック変形の特徴を踏まえ、PIP過伸展を抑える。

  4. 肩関節の外転を制限する：対象は指の関節であり、肩の外転制限は目的に合わない。

問16

正答：2

  1. 水を使うため、渦流浴と同じ対流だけで温まる：水はカップリング媒体であり、温水の流れを利用する渦流浴とは仕組みが違う。
  2. 組織に吸収された音響エネルギーが熱に変わる：直接法でも水中法でも、組織に届いた超音波のエネルギーが吸収され熱に変わる。
  3. 温熱作用が放射に変わる：赤外線のような放射への変更ではない。
  4. 水中法では音響エネルギーは身体に届かない：水を介して超音波を身体へ伝える。
  5. 直接法では変換だが、水中法では必ず伝導のみになる：方法が変わっても超音波の温熱作用は変換である。
