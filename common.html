1. 筋が伸びた情報と、筋を縮める仕組み 目次へ

到達目標

  • 筋紡錘の一次・二次終末を区別できる
  • Ca²⁺の放出・結合・回収の順序を説明できる

最初に押さえる3点

  1. 筋紡錘は筋の長さとその変化を検出する
  2. リアノジン受容体はCa²⁺の出口
  3. トロポニンは放出されたCa²⁺を受け取る

仕組みから理解する

筋紡錘は筋の内部にある感覚受容器です。一次終末に入るIa群線維は長さと伸ばされる速さに反応し、二次終末のⅡ群線維は主に持続した長さを伝えます。「一次＝Ia、二次＝Ⅱ」を入口にして、動的反応と静的反応を分けます。

筋を動かす命令が筋線維に届くと、膜の興奮がT管へ伝わります。骨格筋ではDHP受容体が電位変化を捉え、筋小胞体のリアノジン受容体を介したCa²⁺放出につながります。出たCa²⁺がトロポニンに結合して収縮が進みます。

弛緩するときはCa²⁺ポンプがCa²⁺を筋小胞体へ戻します。出口・受け取り先・回収装置という役割の違いを順番で覚えましょう。受容体の細かな分子構造までは今回の中心にしません。

関係をたどる図式

  1. 筋膜の興奮 → T管・DHP受容体 → リアノジン受容体
  2. 筋小胞体からCa²⁺放出 → トロポニンに結合 → 収縮
  3. Ca²⁺ポンプで回収 → 弛緩

混同しやすい点を比較する

用語何をするか区別の手掛かり
Ia群一次終末。長さと変化の速さを伝える一次のIとIa
Ⅱ群二次終末。主に持続した長さを伝える静的な長さ
リアノジン受容体筋小胞体からCa²⁺を放出出口
トロポニンCa²⁺を受け取り収縮を可能にする結合先
Ca²⁺ポンプ筋小胞体へCa²⁺を回収片付け

資料を閉じて説明する

  1. Ca²⁺の「出口・結合先・回収装置」を順番に言えますか。
  2. 持続的に伸ばされた筋の長さを伝える反応は、動的反応と静的反応のどちらですか。

2. 神経の通り道と、障害される側 目次へ

到達目標

  • 運動路と感覚路の交叉部位を区別できる
  • 脊髄半側障害の左右差を説明できる
  • 大脳の機能局在を対応付けられる

最初に押さえる3点

  1. 交叉＝神経線維が反対側へ渡ること
  2. 痛温覚は脊髄、深部感覚と主な運動路は延髄で交叉
  3. 大脳脚は運動路、小脳虫部は体幹の協調

仕組みから理解する

大脳から身体へ命令を送る主な運動路は、大脳脚・橋・延髄の錐体を通り、線維の多くが延髄下部で反対側へ渡ります。大脳の病変では反対側の麻痺が基本ですが、脊髄内の病変では既に交叉した後なので同側の麻痺が基本になります。

位置覚・振動覚などを伝える後索系は、脊髄では同側を上行して延髄で交叉します。痛温覚の経路は脊髄に入った後、比較的近い高さで交叉します。したがって右脊髄半側障害では、障害より下の右側の運動・深部感覚と、左側の痛温覚が障害されます。痛温覚低下の始まりは病変の数髄節下となることがあります。

局在では、前頭連合野は意欲・計画、頭頂連合野は空間認知、Broca野は言語表出、Wernicke野は言語理解という基本を押さえます。「見る」と「見た物の意味が分かる」も同一ではありません。

関係をたどる図式

  1. 右脊髄半側の障害（障害髄節より下）
  2. 右：運動・位置覚／振動覚の低下
  3. 左：痛覚・温度覚の低下

混同しやすい点を比較する

外側皮質脊髄路随意運動延髄で交叉後、脊髄では同側へ
後索系位置覚・振動覚など延髄で交叉
脊髄視床路痛温覚脊髄で交叉
前頭連合野／頭頂連合野意欲・計画／空間認知前＝行動の計画、頭頂＝空間

  1. 右脊髄半側障害で、右の位置覚と左の痛覚が障害される理由は何ですか。
  2. Broca野とWernicke野の役割を対比してください。

3. 飲み込む・舌を動かす・眼を動かす神経 目次へ

到達目標

  • 嚥下に関わる感覚と運動の神経を区別できる
  • 眼球運動と脳神経を対応付けられる

最初に押さえる3点

  1. 舌の運動は舌下神経
  2. 咀嚼筋は三叉神経、咽頭筋の多くは迷走神経
  3. 外側直筋はⅥ、上斜筋はⅣ、残りの外眼筋はⅢ

仕組みから理解する

嚥下は舌で食塊を送る運動と、咽頭を通過させる運動などが連続する働きです。一つの神経だけでは完結しません。舌の運動は主に舌下神経、咀嚼筋は三叉神経の下顎神経、咽頭筋の多くは迷走神経が担います。舌咽神経は咽頭の感覚などに関わり、茎突咽頭筋の運動も担います。

「舌の感覚」は場所と種類を分けます。前2/3の一般感覚は三叉神経、味覚は顔面神経系、後1/3は舌咽神経が基本です。「顔面神経は舌の感覚」とだけ覚えると、一般感覚と味覚が混ざります。

眼球運動は、外側直筋＝外転神経、上斜筋＝滑車神経、その他の外眼筋＝動眼神経を先に整理します。

関係をたどる図式

  1. 食塊を送る舌：Ⅻ → 咽頭で送る筋の多く：Ⅹ
  2. 咽頭の情報：Ⅸなど → 中枢で統合 → 嚥下運動

内側直筋動眼神経Ⅲ外側直筋はⅥ
上斜筋滑車神経Ⅳ上直筋はⅢ

4. 脳へ行く動脈と、心臓へ戻る静脈 目次へ

到達目標

  • 内頸動脈系と椎骨脳底動脈系を分けられる
  • 上大静脈へ直接注ぐ血管を説明できる

最初に押さえる3点

  1. 「直接」と「経由して」を区別する
  2. 内頸動脈は前・中大脳動脈へつながる
  3. 奇静脈は上大静脈へ注ぐ

仕組みから理解する

脳の動脈は内頸動脈系と椎骨脳底動脈系に分けると整理できます。左右の椎骨動脈が合わさって脳底動脈になります。前交通動脈は左右の前大脳動脈をつなぐもので、内頸動脈から直接出る枝と同じ扱いにはしません。

静脈も流れる順番が大切です。内頸静脈と鎖骨下静脈は腕頭静脈へ合流し、左右の腕頭静脈が上大静脈へ続きます。奇静脈は上大静脈へ直接注ぎます。

肺静脈は左心房、冠状静脈洞は右心房へ注ぎます。「静脈だから全部上大静脈」ではなく、到着する場所を線で結びましょう。

関係をたどる図式

  1. 内頸動脈 → 前大脳動脈・中大脳動脈
  2. 椎骨動脈（左右）→ 脳底動脈 → 後大脳動脈
  3. 内頸静脈＋鎖骨下静脈 → 腕頭静脈 → 上大静脈

混同しやすい点を比較する

血管次につながる代表的な構造誤りを防ぐ点

奇静脈上大静脈直接注ぐ
内頸静脈腕頭静脈上大静脈へは経由する
肝静脈／肺静脈下大静脈／左心房同じ静脈でも行き先が異なる

5. 自律神経と発汗・排尿 目次へ

到達目標

  • 交感神経の作用を臓器ごとに説明できる
  • 発汗と排尿の例外・対比を整理できる

最初に押さえる3点

  1. 交感神経は活動に備える方向
  2. 汗腺は交感神経支配
  3. 排尿筋の収縮は副交感神経が中心

仕組みから理解する

交感神経では、心拍数増加・気管支拡張・消化管運動抑制が基本です。すべての平滑筋を収縮させるわけではなく、臓器の目的によって反応が違います。

膀胱の排尿筋は、尿を出すときに収縮します。この収縮を促すのは主に副交感神経です。蓄尿と排尿を分けると、交感神経を選ぶ問題で迷いにくくなります。

体温調節に中心的なのは広く分布するエクリン汗腺です。汗腺は交感神経支配ですが、エクリン汗腺への節後線維ではアセチルコリンが使われるのが代表的な例外です。

関係をたどる図式

  1. 活動に備える → 心拍↑・気管支拡張
  2. 尿をためる → 排尿筋弛緩
  3. 尿を出す → 副交感神経 → 排尿筋収縮

混同しやすい点を比較する

対象交感神経の基本作用比較
瞳孔散大副交感神経では縮瞳
心臓心拍数増加副交感神経では減少
気管支拡張副交感神経では収縮方向
胃腸運動を抑える方向副交感神経は促進

エクリン汗腺発汗交感神経性だが伝達物質に注意

資料を閉じて説明する

  1. 蓄尿中と排尿時で排尿筋はどう変化しますか。
  2. 体温調節に関わる汗腺と支配神経を答えてください。
